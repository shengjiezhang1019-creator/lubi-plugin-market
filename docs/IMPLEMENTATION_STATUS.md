## 本地已实现

- 独立 Python 项目、空的正式 registry/catalog、示例插件和 Issue 表单。

- 仓库内置 manifest schema 与纯 AST 静态规则，不拉取主程序、不启动主程序或插件；规则内容指纹绑定审核报告。
- manifest `python_dependencies` 严格校验与运行时安装策略记录；不在市场解析、安装或锁定第三方库。

- 人工批准命令、GitHub 权限检查、审核指纹绑定、幂等版本登记与数字版本排序。
- 定时 Release 发现和拒绝记录，网络失败不清空索引。
- 分离验证、AI 与写入任务的 Actions 工作流；写入串行，失败反馈日志链接。

采用 MaiBot 形式：已有版本沿用并警告不匹配，缺失才补装；安装前约束全部已安装版本，避免直接或间接依赖热替换。市场不再证明依赖已安装或功能正确；补装失败仍尝试正常加载，加载失败才按现有事务恢复插件和配置。共享库不回滚。
