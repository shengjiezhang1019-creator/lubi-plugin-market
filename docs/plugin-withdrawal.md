# 下架与恢复插件

仅市场维护者使用。进入市场仓库 Actions → Withdraw or restore plugin → Run workflow，在默认分支填写：

- plugin_name：已登记的插件名称，例如 game_news。
- action：withdraw 下架，restore 恢复。
- reason：操作原因，两种操作均必填。

点击 Run workflow 后查看运行结果和 Summary。任务成功且索引推送完成，才表示操作已发布。
系统核验操作账号的 write/admin 权限，不能仅靠填写一个账号名取得权限。

下架在 registry.json 标记 withdrawn，记录操作人、时间、原因及历史；重新生成 catalog.json 时排除该插件，自动发现跳过它，已打开申请也不能绕过下架状态批准。
版本记录和原仓库归属保留，插件名称仍被占用。恢复后重新展示已批准的最高版本，不会自动批准此前未审核的版本。

用户刷新目录后不再看到下架插件；已有本地副本不会自动卸载，仍可由用户手动卸载。
客户端存在缓存及离线回退，刷新失败或仍使用旧缓存时可能暂时看到旧条目；本功能不是远程强制停用机制。

第一版针对整个插件，不处理撤销某个历史版本。不要只手改 catalog.json，否则后续目录重建可能再次显示插件。
